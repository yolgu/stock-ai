네. **“차익실현 압박률”은 거래소나 증권사에서 표준으로 딱 정의된 공식명은 아니고**, 보통은 아래 3가지를 조합해서 직접 만듭니다.

기준은 간단합니다.

**현재가보다 낮은 가격에서 많이 거래된 물량이 많을수록 → 수익권 참여자가 많음 → 차익실현 후보 물량 증가**
**그 상태에서 실제 매도 체결·매도호가가 강해지면 → 차익실현 압박이 현실화**

관련해서 학술적으로 가장 가까운 개념은 **Capital Gains Overhang, CGO**입니다. Grinblatt & Han 계열 연구에서는 투자자의 기준가격을 과거 거래량·회전율로 추정하고, 현재가와 기준가격의 차이로 미실현 이익 상태를 측정합니다. 후속 연구에서도 기준가격 `RP_t`를 과거 가격의 회전율 가중 평균으로 잡고, `CGO_t = (P_t - RP_t) / P_t`로 계산합니다. ([Springer][1]) 또 처분효과 연구에서는 투자자가 손실 종목은 오래 보유하고 이익 종목은 빨리 파는 경향이 있다고 설명합니다. ([ScienceDirect][2])

## 1. 가장 단순한 공식: 수익권 물량 비율

이게 제일 직관적입니다.

```text
ProfitLongRatio
= Σ VolumeAtPrice[p < P_now] / Σ VolumeAtPrice[all]
```

또는 체결 단위로 보면:

```text
ProfitLongRatio
= Σ Q_i where P_i < P_now / Σ Q_i
```

해석은 이렇습니다.

```text
0.70 = 최근 관측 물량의 70%가 현재가보다 낮은 가격에서 체결됨
```

즉, **대부분의 단기 참여자가 수익권**이라는 뜻입니다. 다만 이 값만으로는 “곧 매도한다”까지는 알 수 없습니다. 그냥 **잠재 차익실현 후보 물량**입니다.

---

## 2. 수익 폭까지 반영한 공식: 가중 차익실현 압박률

단순히 수익권 물량만 보는 것보다, **얼마나 많이 벌고 있는지**까지 반영하는 공식입니다.

```text
WeightedProfitPressure
= Σ [Q_i × max((P_now - P_i) / P_i, 0)] / Σ Q_i
```

여기서:

```text
P_now = 현재가
P_i = i번째 체결 가격 또는 가격대별 평균 가격
Q_i = 해당 체결 수량 또는 가격대별 거래량
```

예를 들어 현재가가 100이고, 대부분의 거래량이 90~95에서 쌓였다면 이 값이 커집니다. 반대로 현재가가 100이어도 거래량 대부분이 99~101에 몰려 있으면 값은 작습니다.

이 공식은 이렇게 해석하면 됩니다.

|        값 | 해석                  |
| --------: | --------------------- |
| 0.00~0.01 | 차익실현 압박 낮음    |
| 0.01~0.03 | 보통                  |
| 0.03~0.06 | 높음                  |
| 0.06 이상 | 급등 후 차익실현 경계 |

다만 종목별 변동성이 다르기 때문에, MU 같은 고변동성 종목은 절대값보다 **ATR 또는 최근 변동성 대비 정규화**가 더 좋습니다.

---

## 3. ATR로 정규화한 공식: 변동성 조정 차익실현 압박률

데이트레이딩에서는 이 버전이 더 실용적입니다.

```text
ATR_Adjusted_ProfitPressure
= Σ [Q_i × max(P_now - P_i, 0)] / (Σ Q_i × ATR_n)
```

또는 퍼센트 기준으로:

```text
ATR_Adjusted_ProfitPressure
= WeightedProfitPressure / ATR_pct
```

여기서:

```text
ATR_pct = ATR_n / P_now
```

해석은 이렇습니다.

```text
1.0 이상 = 평균 진폭 1 ATR만큼의 수익권 물량이 쌓인 상태
1.5 이상 = 차익실현 경계
2.0 이상 = 과열권, 추격 매수 위험 증가
```

이 방식은 단순 수익률보다 낫습니다. 예를 들어 하루에 2% 움직이는 종목의 +5% 수익권과, 하루에 12% 움직이는 종목의 +5% 수익권은 압박의 의미가 다르기 때문입니다.

---

## 4. VWAP 기준 차익실현 압박률

정규장 데이트레이딩에서는 VWAP 기준이 중요합니다. VWAP는 당일 가격×거래량의 누적값을 누적 거래량으로 나눈 값이며, 장중 체결 평균가를 보는 데 사용됩니다. StockCharts도 VWAP를 “당일 거래대금 총합을 거래량으로 나눈 값”으로 설명하고, 장중 데이터 기준으로 계산한다고 설명합니다. ([ChartSchool][3])

```text
VWAP_ProfitPressure
= max((P_now - VWAP_day) / VWAP_day, 0)
```

수익권 물량 비율과 결합하면:

```text
VWAP_Adjusted_ProfitPressure
= ProfitLongRatio × max((P_now - VWAP_day) / VWAP_day, 0)
```

더 실전적으로는:

```text
VWAP_ATR_ProfitPressure
= ProfitLongRatio × max(P_now - VWAP_day, 0) / ATR_n
```

해석은 이렇습니다.

| 조건                                | 의미                      |
| ----------------------------------- | ------------------------- |
| 현재가 > VWAP, ProfitLongRatio 높음 | 당일 참여자 다수가 수익권 |
| 현재가가 VWAP보다 1 ATR 이상 위     | 차익실현 경계             |
| 현재가가 VWAP 위인데 CVD 둔화       | 상승 추세 약화 가능성     |
| 현재가가 VWAP 위인데 매도 체결 증가 | 차익실현 현실화 가능성    |

---

## 5. 실제 매도 압력까지 반영한 공식

잠재 압박만으로는 부족합니다. 실제로 매도가 나오는지 확인하려면 체결 방향을 붙여야 합니다.

```text
SellPressure
= SellVol / (BuyVol + SellVol)
```

또는 매수·매도 불균형으로:

```text
TradeImbalance
= (BuyVol - SellVol) / (BuyVol + SellVol)
```

차익실현 압박률에 결합하면:

```text
RealizedProfitTakingPressure
= ProfitLongRatio
× max((P_now - VWAP_day) / VWAP_day, 0)
× max(-TradeImbalance, 0)
```

`TradeImbalance`가 음수라는 것은 매도 체결 우위입니다. 따라서 `max(-TradeImbalance, 0)`을 곱하면, **수익권 물량이 많고 실제 매도 체결까지 강해질 때만 압박률이 커집니다.**

---

## 6. 호가까지 반영한 공식

호가 데이터가 있으면 더 정교하게 만들 수 있습니다. Order Book Imbalance는 보통 아래처럼 계산합니다. QuestDB도 기본식을 `Bid Volume - Ask Volume`을 양쪽 합으로 나눈 값으로 제시하고, 값이 음수면 매도 압력이 강한 상태로 해석합니다. ([QuestDB][4])

```text
OBI_k
= (ΣBidSize_k - ΣAskSize_k) / (ΣBidSize_k + ΣAskSize_k)
```

차익실현 압박에 붙이면:

```text
Orderbook_ProfitTakingPressure
= ProfitLongRatio
× max((P_now - VWAP_day) / VWAP_day, 0)
× max(-TradeImbalance, 0)
× max(-OBI_k, 0)
```

이 공식은 꽤 실전적입니다.

```text
수익권 물량 많음
+ VWAP 위 과열
+ 매도 체결 우위
+ 호가상 매도 물량 우위
= 차익실현 압박 현실화
```

---

## 7. CGO 기반 공식: 중장기/스윙에도 쓸 수 있는 방식

학술적으로 가까운 공식은 이겁니다.

```text
CGO_t = (P_t - RP_t) / P_t
```

여기서 `RP_t`는 투자자들의 추정 평균 기준가격입니다. 후속 연구에서는 `RP_t`를 과거 가격의 회전율 가중 평균으로 계산합니다. ([Springer][1])

이를 차익실현 압박률로 바꾸면:

```text
CGO_ProfitTakingPressure
= max(CGO_t, 0)
```

정규화하면:

```text
Normalized_CGO_Pressure
= clip(max(CGO_t, 0) / Threshold, 0, 1)
```

예를 들어 `Threshold = 0.15`로 두면:

```text
CGO = 0.03 → 압박률 0.20
CGO = 0.075 → 압박률 0.50
CGO = 0.15 이상 → 압박률 1.00
```

단기 데이트레이딩에서는 `RP_t`를 몇 년치가 아니라 **당일 VWAP, 최근 60분 VWAP, 최근 20봉 VWAP**로 바꿔 쓰는 게 더 맞습니다.

## 8. 제가 추천하는 최종 공식

데이트레이딩용으로는 이 조합이 제일 낫습니다.

```text
ProfitTakingPressureScore
= 100 × [
  0.30 × ProfitLongRatio
+ 0.25 × VWAP_ATR_Extension
+ 0.20 × SellFlowPressure
+ 0.15 × AskBookPressure
+ 0.10 × VolumeExpansion
]
```

각 항목은 이렇게 계산합니다.

```text
ProfitLongRatio
= ΣQ_i where P_i < P_now / ΣQ_i
```

```text
VWAP_ATR_Extension
= clip(max(P_now - VWAP_day, 0) / ATR_intraday, 0, 1)
```

```text
SellFlowPressure
= clip(max(SellVol - BuyVol, 0) / (BuyVol + SellVol), 0, 1)
```

```text
AskBookPressure
= clip(max(ΣAskSize_k - ΣBidSize_k, 0) / (ΣAskSize_k + ΣBidSize_k), 0, 1)
```

```text
VolumeExpansion
= clip(CurrentVolumeRate / AvgVolumeRate_N, 0, 2) / 2
```

최종 해석은 이렇게 잡으면 됩니다.

|  Score | 해석                  |
| -----: | --------------------- |
|   0~20 | 차익실현 압박 낮음    |
|  20~40 | 보통                  |
|  40~60 | 경계                  |
|  60~80 | 강한 차익실현 압박    |
| 80~100 | 급락/윗꼬리 위험 높음 |

## 9. 데이터가 부족할 때 쓰는 간이 공식

호가·체결 방향이 없으면 이 정도로 줄이면 됩니다.

```text
SimpleProfitTakingPressure
= 100 × ProfitLongRatio × VWAP_ATR_Extension
```

또는 일봉만 있을 때:

```text
DailyProxyProfitTakingPressure
= 100 × max((Close - VWAP_20D) / ATR_14D, 0)
```

최근 급등주에서는 이 간이 공식도 꽤 쓸 만합니다.

## 핵심 정리

제가 실전 모델에 넣는다면 아래 순서로 씁니다.

```text
1단계: 수익권 물량 비율
ProfitLongRatio = ΣQ_i(P_i < P_now) / ΣQ_i
```

```text
2단계: 수익 폭 반영
WeightedProfitPressure = Σ[Q_i × max((P_now - P_i)/P_i, 0)] / ΣQ_i
```

```text
3단계: VWAP/ATR 정규화
VWAP_ATR_Extension = max(P_now - VWAP_day, 0) / ATR_intraday
```

```text
4단계: 실제 매도 압력 반영
RealizedPTP = ProfitLongRatio × VWAP_ATR_Extension × max(-TradeImbalance, 0)
```

```text
5단계: 호가 압력 반영
FinalPTP = RealizedPTP × max(-OBI_k, 0)
```

즉, **차익실현 압박률은 “수익권 물량 × 과열 정도 × 실제 매도 체결 × 매도호가 우위”로 보는 게 가장 깔끔합니다.**

[1]: https://link.springer.com/article/10.1007/s40822-024-00285-9 "Firm-specific attributes and capital gains overhang | Eurasian Economic Review | Springer Nature Link"
[2]: https://www.sciencedirect.com/science/article/abs/pii/S0304405X05000747 "Prospect theory, mental accounting, and momentum - ScienceDirect"
[3]: https://chartschool.stockcharts.com/table-of-contents/technical-indicators-and-overlays/technical-overlays/volume-weighted-average-price-vwap "Volume-Weighted Average Price (VWAP) | ChartSchool | StockCharts.com"
[4]: https://questdb.com/glossary/order-book-imbalance/ "Order Book Imbalance | QuestDB"

결론부터 말씀드리면, 제시하신 글의 방향은 **대체로 맞습니다.** 다만 실전 지표로 쓰기에는 가장 중요한 문제가 있습니다.

**“현재가보다 낮은 가격에서 거래된 물량 = 아직 보유 중인 수익권 물량”으로 보면 과대추정됩니다.**
거래량은 매수자와 매도자가 바뀐 결과라서, 그 물량이 지금도 같은 투자자에게 남아 있는지 알 수 없습니다. 그래서 더 좋은 방식은 **회전율로 생존 보유 물량을 조정한 기준가격**, 그리고 **실제 매도 압력이 발생했는지 보는 OFI/CVD/호가 변화**를 분리하는 것입니다.

현재 MU 기준으로 웹 데이터만 가지고 산출하면, **차익실현 압박률은 낮음~보통**, 반대로 **본전 매물·상단 매물 압박은 높은 편**으로 나옵니다.

## 2. 가장 큰 수정 포인트

원문은 차익실현 압박을 하나의 값으로 만들려고 했는데, 실전에서는 아래처럼 나누는 편이 더 정확합니다.

| 구분                   | 의미                                  | 필요한 데이터                            |
| ---------------------- | ------------------------------------- | ---------------------------------------- |
| **잠재 차익실현 압박** | 수익권 참여자가 얼마나 많은가         | 가격대별 거래량, VWAP, ATR, 회전율       |
| **실현 차익실현 압박** | 실제로 매도 체결이 나오고 있는가      | CVD, aggressive sell volume, OFI         |
| **본전 매물 압박**     | 현재가 위에 물린 물량이 얼마나 있는가 | Volume Profile, turnover-adjusted RP     |
| **유동성 충격 증폭률** | 매도 물량이 나올 때 가격 충격이 큰가  | 스프레드, 호가 깊이, Amihud, Kyle lambda |

특히 MU처럼 최근 급등 후 급락한 종목은 **차익실현 압박**보다 **본전 매물 압박 / overhead supply**가 더 중요할 수 있습니다.

## 3. 더 나은 기준 공식

### 3-1. 회전율 조정 기준가격, RP

학술적으로 가장 가까운 기준은 CGO입니다. 최근 연구 설명에 따르면 Grinblatt & Han 방식은 과거 가격을 회전율로 가중하고, 이후 회전율로 생존 확률을 조정한 기준가격 `RP_t`를 사용합니다. CGO는 현재가와 이 기준가격의 차이로 계산됩니다. ([Springer][1])

```text
RP_t =
Σ [ Turnover_i × Survival_i × Price_i ]
/ Σ [ Turnover_i × Survival_i ]
```

```text
Survival_i =
Π(1 - Turnover_j) for j after i
```

```text
CGO_t = (P_t - RP_t) / P_t
```

해석은 이렇게 잡습니다.

```text
CGO > 0  : 평균 보유자가 수익권 → 차익실현 후보
CGO < 0  : 평균 보유자가 손실권 → 본전 매물/저항 후보
```

이 방식이 단순 `VolumeAtPrice[p < P_now]`보다 낫습니다. 이유는 “그 가격에서 거래된 물량이 아직 남아 있는가”를 회전율로 조정하기 때문입니다.

---

### 3-2. 잠재 차익실현 압박, Potential PTP

```text
ProfitBreadth =
Σ W_i × I(P_i < P_now) / Σ W_i
```

```text
ProfitGainMass =
Σ W_i × max(P_now - P_i, 0)
/ (Σ W_i × ATR)
```

```text
VWAP_Extension =
max(P_now - VWAP, 0) / ATR
```

```text
PotentialPTP =
100 × [
  0.45 × ProfitBreadth
+ 0.35 × clip(ProfitGainMass, 0, 1)
+ 0.20 × clip(VWAP_Extension, 0, 1)
]
```

이 값은 **“팔고 싶어질 수 있는 잠재 물량”**입니다. 실제 매도가 이미 나오고 있다는 뜻은 아닙니다.

---

### 3-3. 실현 차익실현 압박, Realized PTP

실전에서는 단순 TradeImbalance보다 **OFI, Order Flow Imbalance**를 우선하는 게 좋습니다. Cont, Kukanov, Stoikov 연구는 짧은 시간 구간에서 가격 변화가 주문흐름 불균형, 즉 최우선 bid/ask의 수요·공급 불균형에 주로 의해 설명되고, OFI와 가격 변화 사이에 선형 관계가 있다고 보고합니다. ([arXiv][4])

```text
SellOFI =
clip(-zscore(OFI), 0, 1)
```

```text
AggressiveSellRatio =
SellVol / (BuyVol + SellVol)
```

```text
AskBookPressure =
clip((AskDepth - BidDepth) / (AskDepth + BidDepth), 0, 1)
```

```text
RealizedPTP =
100 × [
  0.45 × SellOFI
+ 0.30 × AggressiveSellRatio
+ 0.25 × AskBookPressure
]
```

여기서 핵심은 **PotentialPTP와 RealizedPTP를 곱해서 하나로 죽이지 않는 것**입니다. 곱셈식은 특정 데이터가 0이거나 결측이면 전체 신호가 사라집니다. 그래서 실전 화면에서는 둘을 분리해서 보는 편이 좋습니다.

```text
PTP_Final =
0.55 × PotentialPTP
+ 0.45 × RealizedPTP
```

단, `RealizedPTP`는 체결 방향·호가·OFI가 있을 때만 계산합니다.

---

### 3-4. 본전 매물 압박, Overhead Supply Pressure

현재가가 최근 평균 매입가보다 아래에 있으면, 차익실현보다 이 지표가 더 중요합니다.

```text
OverheadSupplyRatio =
Σ W_i × I(P_i > P_now) / Σ W_i
```

```text
OverheadLossMass =
Σ W_i × max(P_i - P_now, 0)
/ (Σ W_i × ATR)
```

```text
OverheadSupplyPressure =
100 × [
  0.60 × OverheadSupplyRatio
+ 0.40 × clip(OverheadLossMass, 0, 1)
]
```

이 값이 높으면 가격이 반등할 때마다 **본전 매도, 손실 축소 매도, 저항 매물**이 나올 가능성이 큽니다.

## 5. MU에 대한 해석

현재 MU는 **차익실현 압박이 큰 자리라기보다는, 반등 시 본전 매물과 저항 매물이 강하게 나올 수 있는 자리**로 보는 게 더 맞습니다.

이유는 세 가지입니다.

첫째, 회전율 조정 기준가격 `RP`가 약 **$1,072.55**인데 현재가는 약 **$1,005.73**입니다. 즉, 최근 참여자의 평균 기준가격이 현재가보다 위에 있는 상태입니다.

둘째, 단순 가격대별 프록시로도 현재가 아래 수익권 물량은 약 **34%**, 현재가 위 물린 물량은 약 **66%**입니다. 따라서 지금 당장의 핵심 리스크는 “수익권 참여자가 팔아서 밀린다”보다 **$1,032~$1,073 부근에서 본전 매물이 나오는 것**입니다.

셋째, 현재가가 최근 일봉 VWAP 프록시 **$1,058.60** 아래에 있습니다. VWAP는 장중 기준 평균 가격·거래량을 반영하는 지표이며, 단독 매수/매도 신호가 아니라 다른 지표와 함께 봐야 합니다. ([Investopedia][2])

## 7. 원문보다 개선된 최종 지표 세트

실전 모델에는 아래 4개를 따로 넣는 것을 추천드립니다.

| 지표명                     | 공식 요약                             |    현재 MU 산출 | 판단                           |
| -------------------------- | ------------------------------------- | --------------: | ------------------------------ |
| **PotentialPTP**           | 수익권 비중 + 이익 폭 + VWAP/ATR 이격 | **21~27 / 100** | 낮음~보통                      |
| **RealizedPTP**            | Sell OFI + 매도 체결 + ask 압력       |   **계산 불가** | 체결·호가 필요                 |
| **OverheadSupplyPressure** | 현재가 위 물량 + ATR 조정 손실 폭     | **약 63 / 100** | 높음                           |
| **LiquidityImpactRisk**    | Amihud, spread, depth, dollar volume  |       부분 계산 | MU는 거래대금 크지만 변동성 큼 |

Amihud류 유동성 지표는 절대수익률을 거래대금으로 나누어 가격충격을 대략 측정하는 방식입니다. NYU V-Lab 설명에 따르면 Amihud ILLIQ는 큰 거래량이 어느 정도 가격 변화를 유발하는지 보는 거친 가격충격 계수로 사용할 수 있고, 일봉 가격·거래량만 있으면 계산 가능하다는 장점이 있습니다. ([VLab][7])

현재 MU의 단순 Amihud 프록시는 거래대금이 매우 커서 낮게 나오지만, 이건 **“유동성은 크다”**는 의미이지 **“하락 위험이 낮다”**는 의미는 아닙니다. 최근 ATR이 매우 크기 때문에 가격 변동 위험은 여전히 높습니다.


## 9. 최종 정리

제시하신 글은 **개념 방향은 좋지만, 최종 공식은 보완이 필요합니다.**

가장 큰 수정은 이겁니다.

```text
차익실현 압박률 하나로 보지 말고,
1) 잠재 차익실현 압박
2) 실현 차익실현 압박
3) 본전 매물 압박
4) 유동성 충격 위험
으로 분리한다.
```

MU 현재 웹 데이터 기준으로는:

```text
PotentialPTP = 21~27 / 100
RealizedPTP = 계산 불가
OverheadSupplyPressure = 약 63 / 100
CGO Proxy = -6.64%
```

따라서 지금 구간의 핵심은 **차익실현 매도 압박**이 아니라, **$1,032~$1,073 이상에서 나올 수 있는 본전 매물·저항 매물 압박**입니다. 차익실현 압박은 **$1,065 위로 회복한 뒤 $1,097~$1,132로 접근할 때 본격적으로 커지는 구조**로 보는 게 더 적절합니다.
