# TASK-DAT-1M-01 — 1분봉 수집기 완성 계획

## 목표

기존 일봉 수집 경로를 수정하지 않고, Toss `/api/v1/candles`의 `interval=1m` 응답을 무손실로 수집·검증하는 별도 연구용 수집기와 strict read-only 경계를 완성한다. 이 TASK에서는 실제 API를 호출하지 않는다.

## 경계

- 변경 대상: `research/rp-001-s2/`의 신규 1m 모듈과 테스트만
- 재사용 대상: 기존 `HttpRequest`, `HttpResponse`, `RawHttpCapture`, `CanonicalScalar`, credential preflight, canonical JSON/hash 저장 원리
- 변경 금지: 기존 일봉 collector, 동결된 연구 artifact, 운영 앱
- 호출 금지: 실제 API, 주문·정정·취소·계좌·잔고·자산 endpoint

## 실행 순서

1. RED 계약을 고정한다.
   - `nextBefore` 원문 그대로 재호출
   - 페이지 내부 중복 거부
   - 페이지 간 동일 overlap은 한 행으로 병합하되 모든 raw occurrence 보존
   - 동일 UTC instant의 다른 timestamp 표기 또는 값 충돌 거부
   - 반복 cursor, 무진전, 역방향 page, 요청 `before` 이후 봉, page-limit 미완료 거부
   - 빈 terminal 응답 허용, 빈 nonterminal 응답 거부
2. 별도 minute collector를 구현한다.
   - 한 거래일 여러 봉을 허용하고 UTC instant 기준으로 정렬한다.
   - exact scalar lexeme, raw body SHA-256, capture ordinal, raw row index, provider order를 보존한다.
   - `L≤O,C≤H`, `L≤H`, 가격 양수, 거래량 비음수 정수를 Decimal로 검사한다.
   - 결측 봉을 생성하거나 0거래량으로 보간하지 않는다.
3. strict read-only boundary를 구현한다.
   - HTTPS Toss host, `GET /api/v1/candles`, 동결 symbol, `interval=1m`, `count=200`, adjusted mode, bounded cursor만 허용한다.
   - 다른 host·method·path·query·header와 모든 운영 endpoint를 opener 호출 전에 거부한다.
4. GREEN 및 회귀검증을 수행한다.
   - 신규 targeted tests
   - RP-001-S2 전체 unittest
   - 신규 소스에서 주문·계좌·자산 경로와 secret literal이 없는지 정적 검사

## 완료조건

- 모든 신규 RED 테스트가 GREEN이다.
- 기존 S2 테스트가 회귀 없이 GREEN이다.
- 실제 네트워크 호출은 0건이다.
- 신규 processed row가 raw response bytes까지 직접 역추적된다.
- 기존 일봉 파일과 운영 앱 diff가 0이다.

## 후속 실행 TASK

`TASK-DAT-1M-02`에서만 종목·기간을 동결하고 라이브 읽기 전용 수집을 수행한다. 요청한 장기간 전체 수집은 Toss의 실제 1m 보존범위를 먼저 측정한 뒤, 제공 가능한 모든 페이지를 수집하고 제공되지 않는 구간은 `data_unavailable`로 남긴다. confirmation 가격은 별도 동결 전까지 열지 않는다.
