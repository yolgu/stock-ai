# 계층 베이지안 HSMM·경쟁위험 후속 연구 틀

## 문서 지위와 버전 경계

이 문서는 FOMO·차익실현·패닉·회복을 하나의 고정 가중합 점수로 환원하지 않고, 시점별 잠재상태와 향후 사건 전이확률로 추정하는 **후속 연구설계 후보**를 기록한다. 연구 질문은 다음과 같다.

> 시점 `t`까지 실제로 이용 가능했던 정보만으로 행동·유동성 상태와 상태 지속시간을 추정하고, 향후 상호 배타적인 첫 사건의 확률분포를 산출하며, 데이터나 식별력이 부족하면 확률을 만들지 않고 판정을 보류할 수 있는가?

이 설계는 현재 동결된 [`preregistration.json`](../../../research/indicator-validation/preregistration.json) v1.4.0의 후보, 가중치, 임계값, 결과 또는 결론을 변경하지 않는다. v1.4 결과를 본 뒤 제안된 구조이므로 기존 TSLA·NVDA·MU·000660 구간에 적용한 결과는 모두 탐색적이다. 이 문서 자체는 사전등록서도, 검증 완료 보고서도, 채택된 운영 공식도 아니다. 확인 연구는 별도 v1.5 이상 사전등록과 봉인된 외부·전향 표본을 필요로 한다.

따라서 다음 행위는 금지한다.

- 새 상태확률을 v1.4 점수에 사후 가중하거나 기존 점수를 재평가하는 행위
- v1.4 결과가 좋아지도록 상태 수, 상태명, 사전분포, 지속시간 분포 또는 전이 그래프를 정하는 행위
- 이미 관측한 v1.4 구간을 새 모형의 확인 표본이라고 부르는 행위
- 일봉 자료로 관측하지 못한 투자자 감정이나 주문취소를 0으로 대체하는 행위
- 여러 모형 중 외부 표본에서 가장 잘 나온 하나만 보고하는 행위

## 목표 출력

하나의 `0~100` 위험점수 대신, 심볼·거래일·정보마감시점별로 다음을 함께 출력한다.

1. 현재 상태의 **필터링 사후확률** `P(z_t=m | I_t)`와 신용구간
2. 현재 상태의 경과기간과 잔여 지속시간 분포
3. `h`거래일 안에 먼저 발생할 수 있는 상호 경쟁 사건별 누적발생확률 `CIF_k(h)`
4. 어떤 사건도 발생하지 않을 확률
5. 데이터 가용성, 분포외 여부, 확률 보정도와 불확실성
6. `estimated`, `missing`, `not_identifiable`, `abstain` 중 하나의 명시적 상태

여기서

\[
I_t=\{\text{availability timestamp가 예측시점 }t\text{ 이하인 모든 입력}\}
\]

이다. 운영 출력에는 전체 표본을 이용한 스무딩 `P(z_t\mid I_T)`가 아니라 필터링 `P(z_t\mid I_t)`만 허용한다. 스무딩은 사후 사건 해설이나 탐색적 라벨링에는 쓸 수 있지만 예측 성능에 합산할 수 없다.

## 1. 시장 공통요인과 종목 고유 움직임 분리

종목 `s`의 로그수익률을 시장·업종·금리·변동성·환율 요인으로 설명되는 부분과 잔차로 나눈다.

\[
r^{idio}_{s,t}
=
r_{s,t}
-\widehat a_{s,t\mid t-1}
-\widehat\beta_{s,t\mid t-1}^{\top}F_t
\]

- `F_t`의 정확한 구성, 빈도, 소스, 공표시각, 시차는 사전등록한다.
- `a`와 `beta`는 `t`보다 앞선 학습자료에서만 추정한다. 중심 이동창이나 전 표본 회귀는 금지한다.
- 종가 시점에 아직 공표되지 않은 요인은 당일 값으로 간주하지 않는다. 미국·한국 시장의 거래시간 차이는 availability timestamp를 이용해 as-of join한다.
- 요인자료가 없거나 정렬이 모호하면 `r_idio`는 `missing`이며 원수익률로 조용히 대체하지 않는다.

이 분리는 시장 전체 급락을 개별 종목 패닉으로 중복 판정하는 오류를 줄이려는 모델링 장치다. 다만 요인 선택과 베타 추정 자체가 오차를 가지므로 `r_idio`를 진짜 종목 감정의 관측값으로 해석해서는 안 된다.

## 2. 회전율 기반 기준가격 분포

### 2.1 거래물량의 생존 가중치

일별 거래량 `V_i`와 해당 시점의 분할 일관 주식수 또는 유통주식수 `S_i`가 있으면 회전율을

\[
\tau_i=\frac{V_i}{S_i},
\qquad
\widetilde\tau_i=1-e^{-\tau_i}
\]

로 정의한다. `tilde(tau)`는 회전율이 1을 넘을 수 있는 날에도 교체확률을 `[0,1)`에 두기 위한 모델링 변환이며, 실제 계좌별 매도확률이 관측됐다는 뜻은 아니다. 또한 Grinblatt·Han의 원래 회전율 가중식을 그대로 옮긴 것이 아니라 후속 연구에서 검증해야 할 변환 후보다. 원 회전율식과 다른 생존 매핑을 후보 원장에 함께 등록하고 외부 결과를 본 뒤 선택하지 않는다. 시점 `i`에 마지막으로 취득돼 `t`까지 남았다고 보는 비정규화 가중치는

\[
w_{i,t}
=
\widetilde\tau_i
\prod_{j=i+1}^{t}(1-\widetilde\tau_j)
\]

이다. Grinblatt·Han은 회전율과 이후 비거래 생존확률을 결합해 시장의 집계 기준가격을 근사했다. 논문도 이를 실제 보유자 원장의 관측값이 아니라 집계 미실현 자본이익의 프록시로 다룬다. [Grinblatt·Han 원문](https://www.anderson.ucla.edu/documents/areas/fac/finance/prospect_momentum.pdf)

유한 lookback만 사용할 때는 시작일 이전 보유자의 잔존질량

\[
w_{0,t}=\prod_{j=t-L+1}^{t}(1-\widetilde\tau_j)
\]

을 버리면 최근 거래가격 쪽으로 기준가격이 편향된다. v1.5는 다음 중 하나를 사전 고정해야 한다.

- 잔존질량이 사전등록 허용치 아래가 될 때까지 충분한 이력을 사용한다.
- 시작일 이전 보유자의 가격분포에 명시적인 좌측 검열 사전분포를 둔다.
- 잔존질량이 너무 크면 기준가격을 `not_identifiable`로 둔다.

### 2.2 기준가격과 분할 불변성

정규화 가중치와 추정 기준가격은

\[
\bar w_{i,t}=\frac{w_{i,t}}{\sum_{\ell}w_{\ell,t}},
\qquad
RP_t=\sum_i\bar w_{i,t}P_i
\]

로 둔다. 이 단순 표기는 `w_{0,t}`가 사전등록 허용치보다 작을 때만 쓴다. 그렇지 않으면 좌측 검열 가격분포의 기대값과 잔존질량 `w_{0,t}`를 분자·분모에 함께 포함한다. 모든 `P_i`는 시점 `t`와 동일한 분할·통화 기준이어야 한다. 거래량과 주식수는 서로 같은 시점의 native-share 기준이거나 동일한 분할계수로 조정돼야 한다. **거래량만으로는 회전율이 아니므로 `S_i` 없이 `RP_t`를 계산하지 않는다.**

현재 v1.4 입력은 조정가격을 제공하지만 거래량의 분할조정 계약을 확인할 수 없다. 실제 실행기는 알려진 분할일이 포함된 TSLA·NVDA 창에서 거래량 의존 후보를 `unadjusted_split_volume_unit`으로 차단한다. 이 상태에서 원거래량을 그대로 넣은 `RP_t`, `G_t`, `L_t`는 만들 수 없다. 현재 판정 계약과 회귀검사는 [`run_validation.py`](../../../research/indicator-validation/run_validation.py)와 [`test_study_runner.py`](../../../research/indicator-validation/test_study_runner.py)에 보존한다.

## 3. 전망이론 기반 이익·손실 위치 분리

준거가격 대비 가치함수 후보를 다음처럼 둔다.

\[
v(x)=
\begin{cases}
x^{\alpha}, & x\ge 0,\\
-\lambda(-x)^{\beta}, & x<0,
\end{cases}
\qquad
\lambda>1
\]

준거점, 이득·손실 영역의 비대칭과 손실회피는 전망이론의 핵심 개념이지만, 위 power 형식은 운영 가능한 매개변수화 후보이지 1979년 논문이 모든 시장에 대해 고정한 보편식이 아니다. 이 함수가 특정 시장·종목의 실제 투자자 효용함수라고 곧바로 식별되는 것도 아니다. `alpha`, `beta`, `lambda`와 개인 간 이질성은 학습 후보이며 사전등록 전 고정값을 채택하지 않는다. [Kahneman·Tversky 원문](https://www.jstor.org/stable/1914185)

매입가격 후보 `P_i`별 미실현 수익률을 `x_{i,t}=P_t/P_i-1`로 두면

\[
G_t
=
\sum_i\bar w_{i,t}
\bigl[\max(x_{i,t},0)\bigr]^{\alpha},
\]

\[
L_t
=
\sum_i\bar w_{i,t}
\lambda\bigl[\max(-x_{i,t},0)\bigr]^{\beta}
\]

로 이익권과 손실권의 잠재질량을 분리할 수 있다.

- `G_t`는 이익권 물량의 **잠재적 차익실현 공급**이지 실제 매도체결이 아니다.
- `L_t`는 손실권 위치의 잠재 부담이다. 처분효과는 손실 포지션을 오래 보유할 가능성도 시사하므로 `L_t` 증가를 즉시 매도압력 증가로 단조 제약해서는 안 된다.
- 본전 매도, 투매 또는 차익실현이라는 행동명은 투자자별 원가와 실제 매도흐름이 함께 관측되거나 독립된 외부 라벨로 검증될 때만 사용한다.
- 확률가중 함수를 생략한 위 식을 완전한 누적전망이론이라고 부르지 않는다.

## 4. 두 개의 데이터 계층

### 4.1 일봉 행동·가격 계층

일봉 계층의 관측벡터 후보는 다음과 같다.

\[
x^{daily}_{s,t}
=
\bigl(
r^{idio}_{s,t},
\text{ATR-normalized path},
\text{drawdown/run-up},
\tau_t,
RP_t,
G_t,
L_t,
\text{attention},
\text{investor/option/short-flow}
\bigr)
\]

현재 Toss 일봉만으로는 가격경로 특성 일부만 계산할 수 있다. 회전율, 기준가격, 직접 관심도, 투자자 유형별 흐름은 별도 점시점 자료가 필요하다.

비정상 거래량·극단 수익률·뉴스는 관심의 간접 프록시일 뿐이다. Barber·Odean은 개인투자자가 뉴스, 비정상 거래량, 극단 수익률처럼 주의를 끄는 종목의 순매수자가 되는 경향을 실증했지만, 이들 프록시가 완전하지 않다는 점도 명시했다. [Barber·Odean 원문](https://faculty.haas.berkeley.edu/odean/Papers%20current%20versions/AllThatGlitters_RFS_2008.pdf) Da·Engelberg·Gao는 검색량을 더 직접적인 관심 지표로 제안했고, 수익률·거래량·뉴스가 관심 외 요인에도 움직일 수 있음을 보였다. [Da·Engelberg·Gao 원문](https://www3.nd.edu/~zda/Google.pdf)

따라서 OHLCV만으로 학습한 잠재상태는 우선 `price_volume_regime`으로 부른다. 외부 행동 측정치와 사전 고정된 측정모형이 상태명을 구별하지 못하면 `FOMO`, `ProfitTaking`, `Panic`이라는 심리 이름을 붙이지 않는다.

### 4.2 고빈도 미시구조 계층

단순한 `DeltaBidDepth - DeltaAskDepth`는 최우선 호가가격이 이동할 때의 주문장 사건을 충분히 반영하지 못한다. 이벤트 `n`의 best bid/ask 가격과 잔량을 각각 `(P_n^B,q_n^B)`, `(P_n^A,q_n^A)`라 하면 Cont·Kukanov·Stoikov의 사건 기반 정의에 맞춘 순기여량 후보는

\[
\begin{aligned}
e_n={}&
\mathbf{1}_{P_n^B\ge P_{n-1}^B}q_n^B
-\mathbf{1}_{P_n^B\le P_{n-1}^B}q_{n-1}^B\\
&-\mathbf{1}_{P_n^A\le P_{n-1}^A}q_n^A
+\mathbf{1}_{P_n^A\ge P_{n-1}^A}q_{n-1}^A,
\end{aligned}
\]

\[
OFI_{[t,t+\Delta]}=\sum_{n\in[t,t+\Delta]}e_n
\]

이다. 해당 연구는 짧은 구간 가격변화와 OFI 사이의 근사 선형관계, 그리고 시장 depth가 얕을수록 커지는 기울기를 보고했으며 단순 거래량 관계보다 견고했다고 설명한다. 이는 일반 법칙이나 미래수익 보장이 아니라 연구 표본에서의 미시구조적 실증관계다. [Cont·Kukanov·Stoikov 원문](https://arxiv.org/abs/1011.6402)

\[
\Delta p_{t,\Delta}
=
\kappa_{t,\Delta}OFI_{t,\Delta}+\varepsilon_{t,\Delta},
\qquad
\kappa_{t,\Delta}\propto\frac{1}{Depth_{t,\Delta}}
\]

패닉성 사건의 조건부 군집은 다변량 Hawkes 후보로 표현할 수 있다.

\[
\lambda_i(u)
=
\mu_i(u\mid z_u,x_u)
+\sum_j\int_{0}^{u^-}\phi_{ij}(u-v)dN_j(v)
\]

사건 유형은 공격적 매도체결, 공격적 매수체결, bid 취소, ask 취소, 스프레드 확대, 다단계 잔량 고갈 등으로 사전 고정한다. 선형 양의 커널을 쓰면 비음수 intensity와 커널 적분행렬의 안정성 조건을 검사한다. 음의 억제효과가 필요하면 양의 선형 Hawkes에 음의 커널을 억지로 넣지 않고 링크함수가 있는 비선형 모형을 별도 후보로 등록한다.

Hawkes 과정은 과거 사건 이후 다음 사건 intensity가 어떻게 변하는지를 표현한다. 관측자료만으로 특정 주문이 다른 주문을 심리적으로 **원인**이 되게 했다고 증명하지 않는다. 이 계열이 고빈도 금융, 주문장, 변동성 및 전염 연구에 사용돼 왔다는 근거는 Bacry·Mastromatteo·Muzy의 종설에서 확인된다. [Bacry·Mastromatteo·Muzy 원문](https://arxiv.org/abs/1502.04592)

과거 호가 이벤트와 취소·체결 방향이 없는 현재 데이터에는 OFI와 Hawkes를 소급 생성하지 않는다. 스냅숏 간 잔량 차이는 취소, 체결, 신규주문을 구분하지 못하므로 원 이벤트열의 대체물이 아니다.

## 5. 계층 베이지안 행동 HSMM

### 5.1 상태 후보와 의미

후속 연구의 최대 상태 집합 후보는

\[
\mathcal Z=
\{Normal,PreFOMO,FOMO,Exhaustion,ProfitTaking,
PrePanic,Panic,Capitulation,Relief\}
\]

이다. 이는 확정된 최적 상태 수가 아니다. 상태 수, 허용 전이와 상태별 측정 앵커는 v1.5 사전등록 전에 시뮬레이션과 개발자료로 정하고, 봉인 표본에서는 변경하지 않는다.

Hamilton의 국면전환 모형은 관측되지 않는 이산 국면을 확률적으로 추론하는 기반을 제공하지만, 상태 지속시간을 별도로 두는 HSMM은 그보다 확장된 구조다. [Hamilton 원문 정보](https://ideas.repec.org/a/ecm/emetrp/v57y1989i2p357-84.html) HSMM은 HMM의 기하분포 체류시간 제약을 완화해 명시적 상태 지속시간을 둘 수 있다. [Yu의 HSMM 원문](https://www.sciencedirect.com/science/article/pii/S0004370209001416)

### 5.2 지속시간과 전이

상태 `i`에서 `d`거래일 머문 뒤 이탈할 이산 hazard를

\[
\operatorname{logit}e_{i,s,t}(d)
=
a_i+u^{exit}_{i,s}+g_i(d)+\xi_i^{\top}x_t
\]

로 둔다. 이탈이 발생했을 때 허용된 다음 상태 `j in A(i)`의 확률은

\[
P(z_{next}=j\mid z_{current}=i,x_t,s,r)
=
\operatorname{softmax}_{j\in A(i)}
\left(
\alpha_{ij}
+u^{symbol}_{ij,s}
+u^{regime}_{ij,r}
+\gamma_{ij}^{\top}x_t
\right)
\]

로 둔다. `g_i(d)`의 함수족, 최대 지속시간, 상태별 최소 지속시간, 허용 전이 그래프는 후보 원장에 고정한다. 상태의 자기전이를 전이행렬과 지속시간 분포 양쪽에서 중복 표현하지 않는다.

계층효과의 한 예는

\[
u^{symbol}_{ij,s}\sim\mathcal N(0,\sigma^2_{ij,symbol}),
\qquad
u^{regime}_{ij,r}\sim\mathcal N(0,\sigma^2_{ij,regime})
\]

이다. 네 종목만으로 분산 성분과 9개 상태의 많은 전이를 안정적으로 식별하기 어렵기 때문에 강한 정규화, 상태 축소 후보, prior-predictive 검사와 시뮬레이션 기반 표본설계가 필요하다. 사전분포가 사후분포를 사실상 결정하면 `not_identifiable` 또는 `abstain`이지 성공이 아니다.

### 5.3 관측모형과 상태 식별

관측벡터 `y_t`의 상태별 분포를

\[
y_{s,t}\mid z_{s,t}=i
\sim f_i(\theta_i+u_{i,s},\;x_{s,t})
\]

로 둔다. 수익률의 두꺼운 꼬리, 거래량의 0과 비대칭, 자료 빈도 차이를 고려한 구체적 분포족은 사전등록 대상이다.

잠재상태에는 label switching과 의미 중첩 문제가 있다. 상태명을 행동 개념과 연결하려면 다음이 모두 필요하다.

- 상태별 사전 고정 측정 앵커와 방향 제약
- 서로 구별되는 관측분포 또는 전이·지속시간 근거
- 합성자료에서의 상태 회복과 매개변수 회복 실험
- 독립된 행동·흐름 자료에서의 수렴타당도와 판별타당도
- 상태 수를 줄인 기준모형보다 외부 예측력이 낫다는 증거

이를 통과하지 못하면 번호 상태 또는 가격경로 국면으로만 보고한다.

## 6. 경쟁위험과 누적발생확률

### 6.1 사건 정의

한 예측기점에서 다음 **첫 물질적 사건**을 서로 배타적으로 정의한다. 모든 원인이 매 시점의 risk set에 들어가는 것은 아니며 현재 필터링 상태별 적용 집합을 사전등록한다.

- `Normal/PreFOMO`: FOMO 진입, 비-FOMO 하락
- `FOMO/Exhaustion`: 상승 지속, FOMO 소진, 차익실현형 조정
- `ProfitTaking/PrePanic`: 정상화, 패닉 진입
- `Panic/Capitulation`: 추가 하락, 반등·회복
- `Relief`: 정상화, 가짜 완화·재하락

사건이 없는 경우는 경쟁 원인이 아니라 생존확률 `S(h)`로 남긴다. 동일 거래일에 여러 장벽이 닿을 때의 순서 불명확 처리, 우측 검열, 재발 사건과 cooldown은 사전등록한다. 상태확률과 사건발생확률은 서로 다른 출력이며 합쳐서 하나의 점수로 만들지 않는다.

### 6.2 이산시간 CIF

일봉 연구의 주 후보는 이산 원인별 hazard다.

\[
q_k(u\mid I_t)
=
P(T=u,K=k\mid T\ge u,I_t)
\]

\[
S(u\mid I_t)
=
\prod_{v=1}^{u}
\left(1-\sum_{\ell\in\mathcal K}q_\ell(v\mid I_t)\right)
\]

\[
CIF_k(h\mid I_t)
=
\sum_{u=1}^{h}S(u-1\mid I_t)q_k(u\mid I_t)
\]

그러면

\[
S(h\mid I_t)+\sum_k CIF_k(h\mid I_t)=1
\]

이므로 서로 경쟁하는 결과와 무사건 확률의 합이 일관된다. hazard의 계층 선형예측자에는 현재 필터링 상태확률, 경과시간, 일봉 특징, 심볼 효과와 사전 고정 국면 효과를 넣을 수 있다.

### 6.3 Fine–Gray와의 구분

연속시간 원인별 hazard `lambda_k`를 쓰면

\[
CIF_k(h)=\int_0^h S(u^-)\lambda_k(u)du,
\qquad
S(u)=\exp\left[-\sum_\ell\int_0^u\lambda_\ell(v)dv\right]
\]

이다. 반면 Fine–Gray는 원인별 hazard가 아니라 **subdistribution hazard**에 비례위험 구조를 두어 주변 누적발생확률에 대한 공변량 효과를 직접 다루는 별도 접근이다. 두 hazard를 같은 것으로 표기하지 않는다. v1.5의 주모형은 상태전이와 결합하기 쉬운 이산 원인별 hazard로 두고, Fine–Gray는 사전등록된 비교·민감도 모형으로 사용하는 것이 더 명확하다. [Fine·Gray 원문](https://www.tandfonline.com/doi/abs/10.1080/01621459.1999.10474144)

## 7. 결측·식별불가·판정보류 계약

모든 출력은 다음 중 정확히 하나의 상태를 갖는다.

| 상태 | 의미 | 허용 출력 |
| --- | --- | --- |
| `estimated` | 필수 입력, 적용범위, 사후 안정성, 확률 보정 gate를 통과함 | 상태확률·CIF·신용구간·무사건 확률 |
| `missing` | 해당 시점의 필수 필드가 누락·손상·시각 불명확함 | 누락 필드와 영향 범위만 보고 |
| `not_identifiable` | 현재 데이터 계층으로 대상 개념을 원리상 구별할 수 없음 | 필요한 데이터와 식별 실패 사유만 보고 |
| `abstain` | 입력은 있으나 불확실성, 분포외, 표본수, 보정 또는 진단 gate를 통과하지 못함 | 보류 사유와 진단값만 보고 |

추가 계약은 다음과 같다.

- 결측 특징을 0으로 대체하거나 가용 특징만으로 가중치를 재정규화하지 않는다.
- `not_identifiable`을 낮은 위험확률로 변환하지 않는다.
- `abstain` 비율을 숨긴 채 남은 표본의 적중률만 보고하지 않는다.
- 신용구간 폭, posterior entropy, 유효표본수, 분포외 거리, calibration gate의 수치 기준은 외부검증 전에 고정한다.
- 선택적 예측은 risk–coverage 곡선으로 평가하고, 커버리지를 낮춰 적중률만 올리는 보상해킹을 검사한다.

## 8. 대안 비교와 권고

| 후보 | 장점 | 핵심 한계 | 연구 판정 |
| --- | --- | --- | --- |
| 고정 가중합·hysteresis | 단순하고 설명·재현이 쉬움. v1.4 기준선으로 이미 등록됨 | 상태 지속시간, 경쟁 사건, 계층 이질성, 불확실성·보류를 충분히 표현하지 못함 | 폐기하지 않고 필수 기준선·보조 특징으로 유지 |
| 일봉 계층 Bayesian HSMM + 이산 경쟁위험 | 상태 지속시간, 심볼 간 부분 풀링, 다중 결과확률과 불확실성 표현 가능 | 상태 식별·label switching, 계산량, 강한 데이터 요구, 네 종목에서 과매개변수 위험 | **v1.5의 주 도전자 모형**. 아직 채택 공식은 아님 |
| 일봉 HSMM + 고빈도 OFI/Hawkes 결합 | 유동성 철수와 주문사건 군집을 직접 관측하는 방향 | 완전한 호가·체결·취소 이력, 동기화, 별도 검증이 필요하고 현재 소급 불가 | 전향적 데이터가 쌓인 뒤 별도 버전으로 평가 |

권고는 단계적이다. 먼저 데이터 계약을 충족한 일봉 HSMM·경쟁위험을 단순 기준선과 경쟁시킨다. 고빈도 자료가 없으면 OFI/Hawkes 항을 비워 둔 채 임의 재정규화하지 않는다. 고빈도 계층은 충분한 전향 사건자료와 독립 사전등록이 갖춰진 뒤 추가한다. 어느 단계든 외부 우월성이 입증되지 않으면 `채택 가능한 공식 없음`을 유지한다.

## 9. v1.5+ 사전등록과 누수 방지

### 9.1 사전등록 항목

새 버전은 다음을 봉인된 확인자료와 그 label을 열기 전에 원장과 해시로 고정한다. 이미 본 v1.4 개발자료를 사용한 결정은 탐색 결정으로 원장에 남긴다.

- 상태 수, 상태명 사용 조건, 허용 전이 그래프, 지속시간 분포 후보
- 관측변수, 단위, 공표시각, 변환, lookback, 결측 계약
- 시장요인 집합과 베타 추정법
- 회전율 분모, 기업행동 조정법, 좌측 검열 기준가격 처리
- 전망이론 매개변수의 사전분포와 부호·단조 제약
- 계층효과, shrinkage prior, 식별 제약, MCMC/근사추론 알고리즘
- 경쟁사건, horizon, 동일봉 복수장벽·검열·재발 규칙
- 비교모형, 복잡도 예산, tuning grid 전체와 trial ledger
- 판정보류 gate와 risk–coverage 평가법
- 선택 지표, 외부채택 최소효과, 다중검정과 중단 규칙
- random seed, 소프트웨어 버전, 원자료·코드·설정 해시

### 9.2 시간 순서

1. 외부 test fold의 매개변수는 학습구간에서만 추정한다.
2. 최대 outcome horizon만큼 purge하고 사전등록 embargo를 적용한다.
3. inner walk-forward에서만 상태 수·prior 후보·정규화·튜닝을 비교한다.
4. outer test에서는 모형 매개변수를 고정한다. `I_t`를 이용한 상태 필터링은 허용하지만 test label을 이용한 업데이트는 금지한다.
5. 스무딩 상태, 미래 barrier, 최종 샘플 정규화값은 예측 특징으로 들어갈 수 없다.
6. fold를 넘어 학습을 확장할 때 이전 test 구간을 새 학습에 포함할지, embargo를 어떻게 유지할지 사전 고정한다.
7. 원자료의 공표·수정 이력이 있는 요인은 point-in-time vintage를 사용한다.

### 9.3 검증 지표

- 상태: multiclass log loss·Brier score, 상태별 calibration, 지속시간 posterior predictive check
- 경쟁위험: horizon별 Brier·log loss, time-dependent calibration, integrated Brier score, 원인별 오탐·미탐
- 사건: 패닉 미탐률, 오경보 빈도, 선행시간, 같은 사건 중복 탐지율
- 선택적 예측: risk–coverage, abstain 사유별 오류율, 외부 커버리지 안정성
- 경제적 유용성: 사전 고정 비용·지연을 적용한 의사결정 규칙과 단순 무행동 기준선
- 안정성: 심볼·시장·국면·horizon별 효과, 이동블록 bootstrap과 시장 공통사건 cluster
- 복잡도: 단순 가중합·가격 전용 HMM/HSMM·기준위험보다 추가되는 실질 예측력

사후확률이 수치적으로 정교해 보인다는 이유만으로 채택하지 않는다. 확률 보정, 외부 재현, 식별 진단과 기준선 우월성이 모두 필요하다.

## 10. 반증 실험

다음 실험은 최고 성능 모형을 지키는 절차가 아니라 깨뜨리는 절차다.

1. **미래누수 sentinel:** `t+1` 값을 의도적으로 주입한 모형만 비정상적으로 좋아지는지 확인하고, 각 과거 출력이 미래행 추가 후 불변인지 검사한다.
2. **시간 순서 교란:** 특징 블록 순환이동, label 블록 permutation, pseudo-event에서 실모형 성능이 유지되면 기각한다.
3. **상태 회복:** 알려진 상태·지속시간·전이를 가진 합성자료에서 상태와 CIF를 회복하지 못하면 실제자료 해석을 금지한다.
4. **상태 축소:** 9상태 모형이 2~4상태 가격 국면모형보다 외부에서 낫지 않으면 더 단순한 모형을 선택한다.
5. **행동특징 제거:** 관심도, 기준가격, 흐름 특징을 제거해도 같은 성능이면 행동적 설명을 약화하거나 철회한다.
6. **시장요인 placebo:** 미래 또는 관련 없는 요인을 쓰지 않고도 factor residual이 안정적인지, 요인 선택에 따라 결론이 뒤집히는지 검사한다.
7. **기업행동 metamorphic test:** 가격·거래량·주식수를 동일 분할비율로 변환해 `tau`, `RP`, `G/L`, 상태확률이 불변인지 검사한다.
8. **미시구조 ablation:** OFI, depth, Hawkes를 각각 제거하고 중복 집계와 실질적 증분을 검사한다.
9. **사전 민감도:** 합리적인 사전분포 집합에서 상태명·전이·외부 CIF 결론이 유지되는지 검사한다.
10. **분포외 스트레스:** 변동성 급등, 거래정지, 0거래량, 가격제한, 장시간 gap, 시장 동시충격에서 `abstain`이 제대로 작동하는지 검사한다.

## 11. 외부채택 규칙

현재 네 종목·고정 기간은 새 틀을 제안하는 과정에서 이미 관측됐으므로 v1.5의 확인적 외부 증거가 될 수 없다. 채택에는 다음 순서가 필요하다.

1. 현재 v1.4 자료는 설계·디버깅·탐색 전용으로 표시한다.
2. 새 후보와 모든 gate를 고정하고 v1.5 사전등록 해시를 발행한다.
3. 설계에 사용되지 않은 심볼·기간의 봉인된 외부자료 또는 사전등록 이후의 전향자료를 수집한다.
4. 미국과 한국처럼 미시구조가 다른 시장의 성능을 분리 보고한다.
5. 외부자료의 결과를 보기 전에 필요한 사건 수와 정밀도를 simulation-based power/precision 분석으로 정한다. v1.4의 사건당 최소 30개보다 낮추지 않으며 복잡한 상태·전이에는 더 많은 표본을 요구할 수 있다.
6. 모든 사전등록 후보·실패·abstain을 보고하고 다중비교를 보정한다.
7. 복합모형은 단순 기준선보다 외부 잠금 구간에서 확률 품질과 핵심 위해지표가 사전 고정된 최소효과 이상 개선될 때만 남긴다.
8. 한 종목, 한 광풍기 또는 한 horizon에서만 이긴 후보는 채택하지 않는다.
9. 일봉 계층의 검증 결과를 고빈도 계층의 검증으로 전용하지 않는다.
10. 기준을 통과한 후보가 없으면 결과는 `no_adoptable_formula`다.

## 12. 현재 데이터에서 가능한 것과 불가능한 것

| 요소 | 현재 증거 | 지금 가능한 판정 |
| --- | --- | --- |
| 조정 일봉 OHLC | TSLA·NVDA·MU·000660 원자료와 해시가 있음 | 가격경로 특징, 독립 barrier 라벨, 인과적 walk-forward 가능 |
| 거래량 | 값은 있으나 조정가격과의 분할 단위 계약이 확인되지 않음 | 분할 포함 창의 거래량 의존식은 `data_unavailable` 유지 |
| 일별 주식수·유통주식수 | 현재 manifest에 없음 | 회전율 `tau`, 생존가중 `RP`, `G/L`은 `not_identifiable` |
| 시장·업종·금리·변동성·환율 요인 | 현재 연구자료에 없음 | `r_idio`는 `missing`; 원수익률 대체 금지 |
| 검색·뉴스 클릭·개인/기관 흐름·옵션·공매도 | 현재 연구자료에 없음 | 심리·주의·주체별 행동상태를 직접 식별할 수 없음 |
| 과거 체결방향·호가이벤트·취소 | 현재 연구자료에 없음 | OFI·depth 충격·Hawkes는 소급 불가 |
| 심볼 수 | 네 종목 | 큰 계층모형의 종목분산·희귀전이를 확인적으로 추정하기 부족할 가능성이 큼 |
| 기존 결과의 독립성 | v1.4 구간 결과를 이미 사용함 | 새 모형의 탐색·디버깅에는 사용 가능하나 확인 표본으로 사용 불가 |

따라서 현재 즉시 가능한 연구는 다음으로 제한한다.

- v1.4 가격 전용 기준선과 기존 결과의 재현
- 가격경로 상태만 가진 소형 HMM/HSMM 계산 프로토타입
- 합성자료의 상태·지속시간·CIF 회복 실험
- missing/not-identifiable/abstain 계약과 미래불변성 테스트
- 신규 데이터 스키마, reference calculator와 사전등록서 작성

현재 자료만으로는 다음을 증명할 수 없다.

- 실제 투자자의 FOMO·공포·차익실현 의도
- 투자자 취득단가 분포와 전망이론 매개변수
- 주문취소·유동성 철수·패닉의 자기흥분 연쇄
- 일중 패닉의 시작·중간·끝 시각
- 9개 상태와 계층 분산의 안정적 식별
- 이미 본 네 종목 구간에서의 확인적 우월성
- 미래 주가를 보편적으로 맞히는 수학적 정리

## 13. v1.4에서 v1.5+로의 이행

### 13.1 거래량·분할 충돌

v1.4는 조정가격을 쓰지만 거래량 조정계약이 불명확한 분할 포함 창의 거래량 의존 후보를 차단한다. 이 안전조치를 해제하지 않는다. v1.5는 다음 순서로만 회전율 계열을 활성화한다.

1. 기업행동 원장과 일별 split factor를 확보한다.
2. 거래량과 일별 발행·유통주식수의 native/adjusted 단위를 문서화한다.
3. 가격은 동일 현재주식 기준으로 변환하고 `V_i/S_i`의 분할 불변성을 reference test로 증명한다.
4. 좌측 검열 잔존질량과 0거래량·0주식수 계약을 고정한다.
5. 데이터 공급자 간 교차대조와 해시를 통과한 뒤에만 `RP/G/L` 후보를 계산한다.

### 13.2 첫 블록 고정과 사후 제안 충돌

v1.4는 후보 정의·가중치·보정법·threshold 알고리즘을 고정하고 각 fold의 과거 학습구간에서만 적합한다. 새 HSMM은 v1.4 결과를 본 뒤 제안됐으므로 기존 첫 블록을 새 모형의 깨끗한 tuning 블록으로 재사용할 수 없다.

이행 규칙은 다음과 같다.

- v1.4 원장·결과·manifest는 불변 보존한다.
- 현재 전체 구간은 v1.5 모형설계의 `seen_development_data`로 명시한다.
- 상태 수·prior·전이·abstain 기준은 새 외부자료를 열기 전에 동결한다.
- 새 확인 연구는 nested purged walk-forward와 별도 terminal holdout을 사용한다.
- terminal holdout에서는 parameter refit, 상태명 재정렬, threshold 변경을 금지한다.
- 기존 가중합은 새 모형의 입력 후보가 될 수 있지만, 그 경우에도 입력 정의를 v1.5 원장에 등록하고 기준선으로 별도 평가한다.

### 13.3 단계별 경로

| 단계 | 산출물 | 허용 결론 |
| --- | --- | --- |
| A. 데이터 계약 | 기업행동·주식수·factor·availability 원장 | 계산 가능/불가능 |
| B. reference·합성 검증 | 독립 계산기, 분할불변성, 상태·CIF 회복 | 구현 타당/기각 |
| C. 현재자료 탐색 | 소형 상태 후보와 prior 민감도 | 탐색적 후보 축소만 |
| D. v1.5 동결 | 후보 원장, 사전등록, 봉인자료 manifest | 확인 연구 시작 가능 |
| E. 일봉 외부검증 | 전체 후보·실패·abstain 결과 | 일봉 모형의 채택/조건부/기각 |
| F. 고빈도 전향수집 | 순서보존 주문장 사건열 | OFI/Hawkes 별도 연구 가능 |
| G. 결합 외부검증 | 일봉 대 결합모형 증분비교 | 미시구조 계층 활성/비활성 |

## 14. 구현 전 데이터 요구사항

### 필수 일봉 계층

- adjusted와 native OHLC, 거래량, 통화, 거래소 거래일, 종가 확정시각
- split, reverse split, 배당, 합병, ticker 변경의 point-in-time 기업행동 원장
- 일별 발행주식수와 가능하면 유통주식수, 각 필드의 공표·효력 시각
- 시장·업종·금리·변동성·환율 요인과 availability timestamp
- 거래정지, 가격제한, 0거래량, 장시간 gap 표시
- 원시 파일·정제 파일·스키마·수집시각·SHA-256

### 행동상태명에 필요한 추가 측정치

- 검색량·뉴스 노출 또는 클릭의 point-in-time 자료와 revision 정책
- 개인·기관·외국인 흐름 또는 거래주체 분류의 정의와 커버리지
- 옵션 거래량·open interest·skew, 공매도·대차의 공표시차
- 종목별 데이터가 없을 때 시장지표로 대체하지 않는 missing 계약

### 고빈도 계층

- 거래소 timestamp와 수신 timestamp가 모두 있는 순서보존 메시지
- best 또는 다단계 bid/ask 가격·잔량, 신규·수정·취소 이벤트
- 체결가격·수량·aggressor side와 order/sequence identifier
- 장 개시·종료·auction·halt·packet loss·재연결 표시
- tick size, lot size, 기업행동과 세션 캘린더
- OFI 집계창·Hawkes 사건유형보다 충분히 높은 원자료 해상도

## 15. 구현·연구 완료 gate

아래 gate는 구현 전에 v1.5 사전등록에서 수치 기준과 판정자를 고정한다. 한 gate의 실패를 다른 지표의 개선으로 상쇄하지 않는다.

| Gate | 통과 증거 |
| --- | --- |
| G0 버전 격리 | v1.4 파일·해시·결론이 불변이고 v1.5 trial ledger가 별도임 |
| G1 데이터 계보 | 기업행동·공표시각·단위·결측·해시 감사 통과, 분할 metamorphic test 통과 |
| G2 수학·구현 등가성 | 독립 reference calculator와 구현의 범위·단위·인과성·CIF 합계·경계값 일치 |
| G3 잠재상태 식별 | 합성자료 상태·지속시간·전이 회복, label switching 통제, prior 지배 없음 |
| G4 누수 방지 | 필터링 전용 예측, 미래행 불변성, purge/embargo, availability join 테스트 통과 |
| G5 내부 잠금검증 | 전체 후보를 보고하고 단순 기준선 대비 사전 고정 최소효과·보정·risk–coverage 통과 |
| G6 독립 외부검증 | 보지 않은 심볼·기간 또는 전향표본에서 방향·보정·안정성 재현 |
| G7 판정보류 안전성 | OOD·결측·저표본에서 abstain하며 커버리지 선택으로 오류를 숨기지 않음 |
| G8 재현성 | 동일 입력·seed·코드·환경에서 manifest와 결과가 결정적으로 재현됨 |
| G9 미시구조 별도 gate | 순서보존 호가·체결 자료, OFI reference test, Hawkes 진단·안정성·외부 증분 통과 |

G0~G8을 모두 통과하기 전에는 일봉 모형을 `validated`로 부르지 않는다. G9를 통과하기 전에는 OFI/Hawkes 계층을 운영 출력에 포함하지 않는다. 외부 기준선 우월성이 없거나 불확실하면 상태 수나 임계값을 사후 조정하지 않고 `no_adoptable_formula`로 종료한다.

## 결론

계층 Bayesian HSMM과 경쟁위험은 고정 가중합이 표현하지 못한 상태 지속시간, 심볼 이질성, 상호 경쟁 결과와 불확실성을 다룰 수 있는 유력한 **연구 후보**다. 그러나 현재 Toss 일봉만으로는 회전율 기반 취득가격, 인간심리, OFI 또는 Hawkes 사건열을 식별할 수 없으며, 이미 본 v1.4 구간은 새 모형의 확인 증거가 될 수 없다.

따라서 현 시점의 결론은 “새 공식 채택”이 아니라 다음의 연구 결정을 확정하는 것이다.

> v1.4는 변경 없이 보존한다. v1.5+에서는 데이터 계보를 먼저 보완하고, 일봉 HSMM·경쟁위험을 사전등록된 주 도전자 모형으로 검증하며, 불확실하면 보류한다. OFI/Hawkes는 전향적 주문장 자료가 축적된 뒤 별도 검증한다. 모든 gate를 통과한 외부 증거가 없으면 공식은 채택하지 않는다.
