# 연구문서 관리 정책

## 1. 문서의 역할

| 문서 | 역할 | 변경 가능 시점 |
| --- | --- | --- |
| `object.json` | 객체 정체성·상태·의존성·artifact의 SSOT | 동결 전 |
| `README.md` | 사람용 탐색과 현재 지위 | 동결 전, 링크 정정은 기록 후 가능 |
| `protocol.md` | 질문·가설·자료·분석·중단조건 | `preregistered` 이전 |
| `data-contract.md` | 단위·가용시점·계보·결측·기업행동 | 자료 개봉 이전 |
| `evidence*.md` | 지지·반박·무효·한계 | 실행 종료 후 append-only |
| `decision*.md` | 채택·기각·보류와 적용범위 | 독립 검토 후 동결 |
| `report.md` | 전체 연구의 사람이 읽는 해석 | 근거와 결정 이후 |

## 2. 이름과 경로

- 객체 폴더: `<ID>-<stable-kebab-name>`
- 공통 정책은 `governance`, 실제 객체는 `objects`, 생성 양식은 `templates`에 둔다.
- 날짜는 사건의 식별에 필요한 보고서에만 `YYYY-MM-DD`로 사용한다. 객체 정체성은 ID가 담당한다.
- 같은 내용을 두 문서에 복사하지 않는다. 두 번째 문서에서는 원문을 링크한다.
- 외부 artifact도 가능한 한 저장소 root 기준 상대경로로 등록한다.

## 3. 버전과 동결

- descriptor schema와 객체 버전은 `MAJOR.MINOR.PATCH` 형식이다.
- 의미·질문·estimand·평가규칙 변경은 MAJOR 또는 새 객체다.
- 결과에 영향을 주지 않는 명확화는 MINOR다.
- 오탈자·깨진 링크 정정은 PATCH다.
- `preregistered` 객체의 분석규칙을 바꾸는 PATCH는 금지한다.
- `frozen` 객체는 직접 수정하지 않고 정정 객체와 결정기록을 연결한다.

## 4. 출처와 계보

모든 외부 근거는 다음을 기록한다.

- 제목과 발행 주체
- 원문 또는 공식 사양 URL
- 적용한 주장
- 접근일
- 이 연구에 적용한 범위와 적용하지 않은 범위

데이터는 공급자 이름만 기록해서는 부족하다. `DatasetContract`에 원시파일, 수집시점, availability timestamp, 단위, 기업행동, 결측정책, 라이선스, SHA-256을 기록한다.

## 5. 탐색과 확인 분리

- 이미 본 자료는 `seen_development_data`로 표시한다.
- 탐색 결과로 만든 가설은 같은 자료에서 확인됐다고 부르지 않는다.
- 확인 연구는 별도 사전등록과 봉인된 외부 또는 전향표본을 사용한다.
- 모든 시도는 성공 여부와 관계없이 trial ledger 또는 evidence bundle에 남긴다.
- 선택되지 않은 후보와 무효 실행을 삭제하지 않는다.

## 6. 링크와 참조

- 객체 간 의미 관계는 ID로, 파일 접근은 상대경로 링크로 표현한다.
- 링크 대상이 이동해야 하면 먼저 새 객체 또는 adapter 경계를 검토한다.
- catalog에 연구내용을 복제하지 않는다.
- 보고서의 수치 주장은 원시결과가 아니라 해시가 있는 `ExperimentRun` 또는 `EvidenceBundle`을 가리켜야 한다.

## 7. 보안·권리·민감정보

- API key, secret, access token, 계좌정보를 문서·catalog·실행로그에 저장하지 않는다.
- 인증정보는 외부 경계의 일회성 환경변수 또는 승인된 비밀저장소에서만 사용한다.
- 재배포 권한이 없는 원자료는 복제하지 않고 계약·식별자·해시·접근조건만 남긴다.
- 개인 또는 계좌 수준 자료는 익명화·목적제한·보존기간이 정해지기 전 연구객체에 포함하지 않는다.

## 8. 문서 검토 규칙

동결 전 다음을 확인한다.

1. 질문과 estimand가 하나의 의미로 읽히는가?
2. 자료 가용시점과 미래정보 금지가 명시됐는가?
3. 기준선·반증·중단조건이 결과 열람 전에 정해졌는가?
4. 성공·실패·무효·식별불가가 모두 보고 가능한가?
5. 모든 수치 주장이 evidence로 추적되는가?
6. 같은 정의가 다른 문서에 복제되지 않았는가?
7. 비밀정보와 재배포 제한 자료가 포함되지 않았는가?
