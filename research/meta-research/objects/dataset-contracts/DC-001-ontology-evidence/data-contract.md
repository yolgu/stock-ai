# DC-001 상태 온톨로지 근거 데이터 계약

## 정체성

- 객체 ID: `DC-001`
- 적용 질문: `RQ-001`
- 적용 study: `ST-ONT-001`
- 계약 버전: `1.0.1`
- 구조화 SSOT: [source-register.json](source-register.json)

이 계약의 source unit은 시장 시계열 행이 아니라 1차 문헌 한 편의 서지·주장 메타데이터다. 저작권 원문을 저장하지 않는다. 제목, 저자, 발행정보, DOI, 공식 URL, 적용 주장과 비적용 범위로 이루어진 서지·주장 메타데이터만 저장한다.

## Source unit 스키마

| 필드 | 형식 | 의미 | nullable |
| --- | --- | --- | --- |
| `sourceId` | 문자열 | `SRC-001`부터 `SRC-014`까지의 고유 ID | 아니요 |
| `title` | 문자열 | 1차 문헌 제목 | 아니요 |
| `authors` | 문자열 배열 | 문헌에 표시된 저자 순서 | 아니요 |
| `publisher` | 문자열 | 발행기관 또는 저널 발행주체 | 아니요 |
| `year` | 정수 | 발행연도 | 아니요 |
| `doi` | 문자열 | DOI 식별자 | 아니요 |
| `officialUrl` | HTTPS URL | DOI, 공식 working paper 또는 공식 저자 제출본 경로 | 아니요 |
| `accessedAt` | ISO 날짜 | 설계 코퍼스 접근일 | 아니요 |
| `primarySource` | 불리언 | 1차 문헌 여부이며 반드시 `true` | 아니요 |
| `corpusRole` | 문자열 | 반드시 `design_seen_before_freeze` | 아니요 |
| `appliedClaims` | 비어 있지 않은 문자열 배열 | 이 연구에 실제 적용하는 주장 | 아니요 |
| `nonApplicableClaims` | 비어 있지 않은 문자열 배열 | 이 연구에 일반화하지 않는 범위 | 아니요 |

## 코퍼스와 시간 계약

- source unit 수: 정확히 14개
- 접근일: 모든 행이 `2026-07-10`
- 코퍼스 역할: 모든 행이 `design_seen_before_freeze`
- 시간 의미: 14개 문헌은 프로토콜 hash 이전 설계에서 이미 열람된 코퍼스다.
- 연구 의미: 이 코퍼스를 사후 확인자료 또는 독립 확인근거라고 부르지 않는다.
- 시장자료: 이 계약은 시장 데이터, 계좌자료, 설문 원응답 또는 주문장 원자료를 포함하지 않는다.

## 적용과 비적용 계약

각 source unit은 온톨로지 규칙에 실제 사용한 `appliedClaims`와, 논문이 지지하지 않거나 이 연구가 일반화하지 않는 `nonApplicableClaims`를 함께 가져야 한다. 둘 중 하나라도 누락되거나 비어 있으면 수락을 차단한다. 같은 가격 입력에서 파생한 복수 점수는 독립 측정방법으로 취급하지 않는다.

## 권리와 보안

- 저장범위: 서지·주장 메타데이터만 저장
- 저작권 문헌 전문, 표 전체, 장문 인용: 저장 금지
- 개인정보와 계좌자료: 저장하지 않음
- 인증정보와 비밀값: 저장하지 않음
- 재배포: 공식 URL을 통한 원문 접근만 안내하며 원문을 재배포하지 않음

## 정정·철회와 amendment

출처의 정정·철회, DOI 변경, 공식 URL 이동, 서지 오류 또는 주장 적용범위 오류가 확인되면 기존 동결 프로토콜을 조용히 덮어쓰지 않는다. 변경 이유, 영향받는 `sourceId`, 이미 생성된 판정에 대한 영향과 열람 시점을 기록한 amendment를 새 버전으로 만든다.

## 수락조건

1. 14/14 source unit이 정확히 존재한다.
2. 모든 source unit은 1차 문헌이며 `primarySource=true`다.
3. 모든 필수 필드가 존재하고 비어 있지 않다.
4. 모든 source unit의 적용 주장과 비적용 범위가 각각 하나 이상이다.
5. DOI와 공식 URL이 기록되어 있다.
6. 저작권 원문과 장문 인용이 포함되지 않는다.
7. JSON은 UTF-8, key 정렬, compact, trailing LF 없는 canonical bytes다.

필수 비적용 범위 누락, 2차 출처 혼입, 출처 수 부족, 원문 저장, 동결 뒤 무기록 변경은 수락을 차단한다.
