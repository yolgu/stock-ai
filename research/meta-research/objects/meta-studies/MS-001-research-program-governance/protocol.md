# MS-001 연구 프로토콜

## 상태

- 연구 유형: bounded standards synthesis + repository gap analysis
- 프로토콜 지위: 방법 기록
- 외부 사전등록: 없음
- 주의: 초기 공식표준 탐색 이후 작성됐으므로 확인적 사전등록으로 해석하지 않는다.

## 연구 질문

> 기존 v1.4를 변경하지 않으면서 후속 정량금융 연구의 질문·자료·방법·실행·근거·결정을 사람이 읽고 기계가 검사할 수 있게 만드는 최소 문서 구조는 무엇인가?

## 평가 대상

1. 평면 Markdown 문서 모음
2. 완전한 시맨틱 연구객체: RO-Crate + W3C PROV-O 중심
3. 타입이 있는 파일 우선 연구객체: Markdown + `object.json` + 최소 validator

## 평가기준과 가중치

| 기준 | 가중치 | 측정 질문 |
| --- | ---: | --- |
| 추적성 | 0.20 | 주장→근거→실행→자료를 역추적할 수 있는가? |
| 재현성 지원 | 0.20 | protocol·입력·코드·결과를 결박할 수 있는가? |
| 변경 격리 | 0.15 | 기존 연구를 건드리지 않고 새 연구를 추가할 수 있는가? |
| 기계 검증 | 0.15 | 중복·누락·경로·의존성 오류를 자동 검출할 수 있는가? |
| 사람 사용성 | 0.15 | 저장소에서 바로 읽고 작성할 수 있는가? |
| 도입비용 | 0.10 | 외부 서비스·전문 도구 없이 시작할 수 있는가? |
| 상호운용성 | 0.05 | 외부 표준으로 변환할 명확한 경로가 있는가? |

각 기준은 `1=매우 약함`, `2=약함`, `3=충분`, `4=강함`, `5=매우 강함`으로 평가한다.

\[
Score(option)=\sum_j weight_j\times rating_{option,j}
\]

## 출처 포함 기준

- 공식 표준·공식 정책·원 논문
- 연구객체, provenance, 사전등록, 자료패키징, artifact 재현성을 직접 다루는 자료
- 현재 저장소에 실제로 존재하는 protocol·manifest·보고서

## 제외 기준

- 출처가 없는 개인 요약
- 문서관리와 직접 관계없는 일반 생산성 도구
- 원자료 재배포를 전제로 하는 구조
- 현재 저장소를 대규모 이전해야만 적용 가능한 구조

## 분석 절차

1. 현재 v1.4의 강점과 결함을 저장소에서 추출한다.
2. 공식표준이 해결하는 문제와 요구비용을 근거행렬에 기록한다.
3. 세 후보를 동일 기준으로 평가한다.
4. 최고 가중점수 후보가 불변 경계와 보안조건을 위반하지 않는지 확인한다.
5. 채택하지 않은 표준도 향후 adapter 경로로 남긴다.

## 결정 규칙

- 불변 v1.4 경계를 침범하는 후보는 점수와 무관하게 기각한다.
- 비밀정보를 artifact로 요구하는 후보는 기각한다.
- 최고점 후보가 기계 검증 또는 변경 격리에서 `3` 미만이면 채택하지 않는다.
- 점수차가 `0.25` 미만이면 더 단순한 후보를 선택한다.

## 한계

- 한 명의 조사자가 자료선정과 평가를 수행했다.
- 검색 데이터베이스와 검색식이 정식 범위고찰 수준으로 사전등록되지 않았다.
- 점수는 경험적 성능이 아니라 저장소 구조 선택을 위한 명시적 판단이다.
- 외부 연구팀에 의한 사용성·재현성 검증은 수행하지 않았다.
