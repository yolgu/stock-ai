# RP-001 정량 시장행동·상대가치·실행 연구 프로그램

## 프로그램 Goal

> 시장행동 국면, 상대가격 오류, 유동성 변화, 체결 가능성과 꼬리위험 중 어떤 정보가 비용 차감 후 반복 가능한 조건부 기대수익을 만드는지 독립적으로 검증하고, 외부검증을 통과한 OOF 출력만 최종 의사결정식에 통합한다.

## 지위

- 객체 유형: `ResearchProgram`
- 수명주기: `proposed`
- 증거수준: `conceptual`
- 기존 기준선: `RB-001`
- 특권 없는 후보 중 하나: `MC-001`

현재 문서는 연구 프로그램 설계다. 새 공식이 채택됐거나 실거래 효용이 증명됐다는 뜻이 아니다.

## 핵심 원칙

1. 기존 v1.4를 수정하지 않는다.
2. 이미 확인한 TSLA·NVDA·MU·SK하이닉스 구간은 discovery 자료로만 사용한다.
3. 인간의 공포·FOMO·차익실현 의도는 가격만으로 관측됐다고 부르지 않는다.
4. 행동, 상대가치, 미시구조, 체결, 위험 study를 독립적으로 사전등록한다.
5. 단순 기준선보다 복잡한 모형에 우선권을 주지 않는다.
6. 비용·슬리피지·시장충격·CVaR를 제외한 수익은 운영 근거가 아니다.
7. 불확실하거나 식별할 수 없으면 `abstain` 또는 `not_identifiable`을 출력한다.
8. 개별 study의 외부 OOF 결과만 최종 통합에 사용한다.

## 프로그램 완료의 의미

프로그램 완료는 반드시 수익 공식 채택을 뜻하지 않는다. 다음 중 하나의 근거 있는 결론이면 완료될 수 있다.

- 외부검증과 비용 Gate를 통과한 조건부 채택
- 일부 자료·종목·빈도에서만 가능한 제한적 채택
- 설명에는 유용하지만 거래에는 부적합한 `research_only`
- 단순 기준선 우월성이 없는 `reject`
- 필요한 자료·정답이 없는 `not_identifiable`
