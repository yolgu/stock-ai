# 연구객체 Archive

이 경계에는 대체·종료된 연구객체의 봉인본을 보존한다.

## 규칙

- 삭제 대신 후속 객체의 `DecisionRecord`에서 대체 이유를 기록한다.
- archive된 객체의 descriptor와 artifact는 수정하지 않는다.
- 오류 정정은 원문을 덮어쓰지 않고 새 객체·새 버전으로 만든다.
- 원자료를 무조건 복제하지 않는다. 불변 저장 위치, manifest, SHA-256, 접근조건을 보존한다.
- 개인정보·인증정보·라이선스상 재배포할 수 없는 자료는 넣지 않는다.

현재 archive로 이동된 새 연구객체는 없다. 기존 v1.4는 폐기된 객체가 아니라 활성 기준선이므로 `objects/baselines`에 유지한다.
